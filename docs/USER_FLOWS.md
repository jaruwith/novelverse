# User Flows

## Guest discovers and reads

Home/category/search → story detail → start reading → chapter navigation. Attempting follow, like, comment, or report opens the login-required dialog. Guests may continue reading without login.

## Member resumes reading

Role switcher: Member → Home: อ่านต่อ or History/Following → latest read chapter → continue → progress updates visually. State is illustrative and not persisted.

## Member publishes

Dashboard → Create work → choose Novel or Comic → enter metadata and suitability → save draft or publish → manage chapters → create content-type-specific chapter → preview → publish.

## Member manages public identity

Dashboard profile → edit avatar/banner/name/username/bio/social links → preview combined public Member/Creator profile.

## Admin moderates a report

Admin reports → filter/review target → resolve, reject, or hide target → inspect related user/story/comment. Actions show confirmation feedback but do not persist.

## Access behavior

Guest opening member routes sees a permission/login state. Member opening admin routes sees permission denied. The local role switcher makes these states reviewable.
