## รูปแบบ

ใช้หมวด Added, Changed, Deprecated, Removed, Fixed และ Security เมื่อมีข้อมูลที่ตรวจสอบได้ วันที่อ้างอิงใช้วันที่จัดทำเอกสาร ไม่ใช้เป็นวันที่พัฒนา feature หากไม่มีหลักฐาน

## 0.1.0 — 19 กรกฎาคม 2569

### Added

- เพิ่มชุดเอกสารสถาปัตยกรรมและผลิตภัณฑ์ภาษาไทย 13 ไฟล์ใน `docs`
- บันทึก inventory 31 หน้า/สถานะ, 7 component files และ mock data
- สรุปข้อกำหนด การออกแบบระบบ ข้อมูล API/UI roadmap และ decisions จาก implementation ปัจจุบัน

### Changed

- ไม่มีการแก้ไข application, routes หรือ UI

### Security

- ไม่มีการเปลี่ยนแปลงด้าน security; ระบบยังเป็น wireframe และไม่มี authentication/authorization จริง

## ประวัติก่อนหน้า

Repository ไม่มี changelog เดิมและไม่มีข้อมูล release history ที่ใช้ยืนยันได้: **ยังไม่ได้กำหนด**
