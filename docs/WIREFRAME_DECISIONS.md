# Wireframe Decisions

## Confirmed for this prototype

- Public Member Profile and Creator Profile are one page.
- Every Member can publish; there is no separate Creator role.
- No notification center in MVP.
- The Following page replaces notifications.
- Likes apply to chapters only.
- Follows apply to stories only.
- Comments are flat, with no replies or comment likes.
- Story views are summed from chapter views.
- Search appears in the global header on every public page.
- The first visual direction is a light, eye-comfortable theme.
- Desktop and mobile browsers are supported.

## Prototype assumptions to validate

- Creator-follow is shown only as a disabled future placeholder.
- Story reporting is visible on story detail; chapter/comment/user reporting is demonstrated in relevant menus and admin reports.
- Hidden and archived works remain reachable as explicit system-state examples.
- A single suitability self-rating is sufficient for the first publishing flow.
- Member comment hiding is reversible conceptually, though this prototype does not persist it.
